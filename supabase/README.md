# Отзывы и наблюдения посетителей — как включить

Сейчас блоки «Tips & Stories From Travellers» (парки, города, маршруты) и
«Seen One? Tell Us About It» (животные) работают в **демо-режиме**: при
`npm run dev` всё сохраняется только в твоём браузере. В собранном сайте
без ключей эти блоки не показываются.

Чтобы отзывы реально сохранялись для всех посетителей — подключи Supabase
(бесплатного тарифа хватит).

## 1. Создать проект

1. Зайди на https://supabase.com → **Start your project** → войди.
2. **New project** → придумай имя (например `still-wilds`), пароль базы
   (сохрани его), регион **Canada (Central)**.
3. Подожди 1–2 минуты, пока проект создастся.

## 2. Создать таблицы

1. В проекте слева **SQL Editor** → **New query**.
2. Скопируй туда весь файл `supabase/schema.sql` → **Run**.
   Должно появиться «Success». Этот же файл создаёт два хранилища для фото
   посетителей: `photos-pending` (закрытое, на проверке) и `photos`
   (открытое, опубликованные). Если файл обновился — просто запусти его ещё раз.

## 3. Создать себе вход модератора

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введи свой e-mail и пароль, отметь **Auto Confirm User** → **Create**.
3. Снова **SQL Editor** → **New query**, вставь (подставь свой e-mail) → **Run**:

   ```sql
   insert into public.moderators (user_id)
   select id from auth.users where email = 'ТВОЙ-EMAIL@example.com';
   ```

4. **Authentication** → **Sign In / Providers** → выключи
   **Allow new users to sign up** — посетителям аккаунты не нужны,
   так никто посторонний не сможет зарегистрироваться.

## 4. Подключить сайт

1. Слева **Project Settings** → **API**.
2. Скопируй **Project URL** и ключ **anon public**.
3. В корне проекта создай файл `.env.local` (он не попадает в git):

   ```
   VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```

4. Перезапусти `npm run dev`. Тех же двух переменных хватит и на хостинге
   (Vercel / Netlify → Settings → Environment Variables).

`anon public` ключ — публичный, его можно держать в сайте: права
посетителей ограничены правилами в `schema.sql` (только читать
одобренное и отправлять новое в очередь).

## 5. Модерация

Открой `/moderation` на сайте → войди своим e-mail и паролем.

- **Waiting** — новые записи. **Approve** — опубликовать, **Reject** — отклонить.
- **Published** — уже на сайте; **Unpublish** — убрать.
- **Delete** — удалить навсегда (вместе с фото).
- Фото к записи видны прямо в карточке; нажми на фото, чтобы открыть крупно.
  При **Approve** фото публикуются вместе с текстом, при **Reject** — удаляются.

Что не публиковать (это же написано посетителям под формой):
- фото, где животное кормят, приманивают или к нему подошли вплотную;
- чужие лица крупным планом без разрешения;
- точные места животных (тропа, GPS, «у третьего столба») — особенно сов,
  журавлей, гнёзд;
- истории о кормлении, приманке, подходе вплотную к животным;
- личные данные, рекламу, ссылки.

## Что ещё нужно перед запуском

- **Политика конфиденциальности** (Privacy Policy). Мы собираем только имя
  и текст, без e-mail, но страница всё равно нужна (закон PIPEDA).
- По желанию позже — **Cloudflare Turnstile** (невидимая «капча»), если
  будет много спама. Сейчас от спама защищают поле-ловушка для ботов,
  лимит 60 записей за 10 минут и ручная модерация.
